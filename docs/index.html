🚀 Local quick start
  1. Clone the repository and run npm install.
  2. Copy .env.example to .env (never commit real keys).
  3. Edit config/targets.json with your websites, phone numbers, and domains.
  4. Install Playwright: npx playwright install chromium.
  5. Run checks: npm run test:e2e
  6. Open reports/run-report.html for results.
npm install
npx playwright install chromium
cp .env.example .env
npm run test:e2e
open reports/run-report.html

For placeholder example.com targets:

ALLOW_PLACEHOLDER_TARGETS=true npm run test:form-popup

⚙️ Config (targets.json)

Each target supports:

  • website.url, formUrl, safeToSubmit, formSelector, expectedSuccessText
  • website.popupChecks[]
  • phone.enabled, number, expectedBehaviour
  • domain.enabled, domain, ip

Set enabled: false on a target to skip it.

{
  "targets": [{
    "name": "Main Website",
    "enabled": true,
    "website": {
      "url": "https://yoursite.com",
      "safeToSubmit": false
    },
    "phone": {
      "enabled": true,
      "number": "+441234567890"
    },
    "domain": {
      "enabled": true,
      "domain": "yoursite.com",
      "ip": "203.0.113.10"
    }
  }]
}
⚡ NPM scripts 
npm run test:e2e          # all checks + report
npm run test:form-popup   # Playwright only
npm run test:phone        # Twilio phone checks
npm run test:domain       # domain/IP health
npm run test:twilio       # SMS/OTP verification
npm run report            # build from existing JSON
npm run clean:reports     # remove generated files
🔑 Environment variables

Copy .env.example to .env and fill in only what you need.

Variable Required for If missing
TWILIO_ACCOUNT_SID, AUTH_TOKEN, FROM_NUMBER Phone tests Skipped
MXTOOLBOX_API_KEY API reputation lookups DNS fallback
NOTIFIER_WEBHOOK_URL Alerts Skipped
🔒 Safety rules
  • API keys stay in .env (gitignored) — never committed.
  • Missing API keys return skipped, not fake passes.
  • Forms are not submitted unless safeToSubmit: true.
  • Phone answer detection uses Twilio status polling only.
🌐 Website form testing

Safe-by-default form automation:

  • Opens each target URL and verifies the form is visible.
  • Fills fields with test data (configured fields or auto-detected inputs).
  • Only submits when safeToSubmit: true.
  • Checks success selectors, URL tokens, and expected confirmation text.

npm run test:form-popup — Playwright website checks only.

🪟 Popup, banner & live chat
  • Popups & cookie banners — selector visibility with optional expected text and criticality flags.
  • Newsletter & CTA blocks — validate conversion elements before campaigns go live.
  • Live chat widgets — mark as critical to fail fast when support entry points disappear.

Configure in website.popupChecks[] with name, selector, expectedText, critical.

📞 Phone test automation

Ready: Outbound line checks via Twilio from config/targets.json. Records honest statuses — call started, answered, busy, no answer, failed, or skipped.

Expandable: Current version polls Twilio call status. For deeper IVR/answer analytics, add a Twilio status callback URL in environment variables.

  • npm run test:phone — phone checks only
  • npm run test:twilio — optional SMS/OTP verification
🛡 Domain & IP health

MXToolbox (when API key exists): MX, SPF, DMARC, and blacklist lookups per target domain/IP.

DNS fallback (no API key): Clearly skips API checks and uses DNS for MX/SPF/DMARC, resolution, and reverse lookup.

npm run test:domain — domain/IP/email health only.

📊 Reports & outputs

Every full run produces:

  • JSON: reports/run-report.json — machine-readable for dashboards or CI artifacts.
  • HTML: reports/run-report.html — manager-friendly failures, warnings, and next actions.

Category reports saved separately (phone, form/popup, domain). Screenshots and network logs in artifacts/.

npm run report — build from existing JSON · npm run clean:reports — remove generated files.
