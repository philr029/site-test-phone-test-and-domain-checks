Domain and IP health checks

Ready

MXToolbox when API key exists

Runs MX, SPF, DMARC, and blacklist lookups per target domain/IP.

Fallback

DNS checks without API key

If MXTOOLBOX_API_KEY is missing, the tool clearly skips API checks and uses DNS fallback for MX/SPF/DMARC, resolution, and reverse lookup.

Reports

Every full run produces:

  • JSON: machine-readable run summary for dashboards or CI artifacts.
  • HTML: manager-friendly report highlighting failures, warnings, and next actions.

Category reports are also saved separately (phone, form/popup, domain).

Setup guide

  1. Clone the repository and run npm install.
  2. Copy .env.example to .env (never commit real keys).
  3. Edit config/targets.json with your websites, phone numbers, and domains.
  4. Install Playwright browser: npx playwright install chromium.
  5. Run checks: npm run test:e2e then open reports/run-report.html.
  6. Enable GitHub Actions secrets for Twilio and MXToolbox in repository settings.
  7. Publish this page from the /docs folder via GitHub Pages.
# config/targets.json (simplified)
{
  "targets": [{
    "name": "Main Website",
    "enabled": true,
    "website": { "url": "https://yoursite.com", "safeToSubmit": false },
    "phone": { "enabled": true, "number": "+441234567890" },
    "domain": { "enabled": true, "domain": "yoursite.com", "ip": "203.0.113.10" }
  }]
}
